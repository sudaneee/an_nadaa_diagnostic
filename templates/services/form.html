Report Template Help

The report template defines what parameters will appear in the medical report.

Example Template:
{
    "parameters": [
        {
            "name": "Malaria Parasite",
            "type": "select",
            "options": ["Positive", "Negative"],
            "required": true
        },
        {
            "name": "Comments",
            "type": "textarea",
            "required": false
        }
    ]
}

Parameter Types:

  • text - Short text input
  • textarea - Long text area
  • number - Numeric input (use with 'unit' and 'normal_range')
  • select - Dropdown (requires 'options' array)
